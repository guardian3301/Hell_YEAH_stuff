A small NeoForge mod that adds movement tools and questionable alchemy to
Minecraft 1.21.1 — grappling hooks, crossbows on bolts, and syringes full of
things you probably shouldn't inject.

## What's inside

- **Grapple darts** — Dying Light 2 style hook: the bolt sticks, the rope holds,
  releasing slings you forward.
- **Multi crossbow** — fires darts: regular, explosive and grapple.
- **Rail crossbow** — bolt-firing crossbow with the *Amethyst Condenser*
  enchantment, which grows amethyst ammo over time.
- **Battle syringe** — a sword that draws effects from your own blood and
  injects them into whatever you hit. Shift+right-click empties it into yourself.
- **Spectral capacitor** — a grenade that only charges while you move.
- **Tactical holster** — belt accessory (Curios) that stows one weapon behind
  a keybind.
- Plus the *Dash* and *Amethyst Grenades* enchantments, the *Sharp Amethyst
  Dust* block, the *Hunter's Camp* structure, and the **suspicious syringe**:
  dungeon loot whose contents stay masked as `????? (??:??)` until you use it.

## Requirements

- Minecraft **1.21.1**
- NeoForge **21.1.x**
- Java **21**

[Curios](https://www.curseforge.com/minecraft/mc-mods/curios) is optional — only
the belt accessories need it.
